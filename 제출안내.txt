Flask 실습 제출 안내

제출할 저장소 URL
https://github.com/juanxiu/2026_osp_project_gitden

첨부할 스크린샷
1. screenshots/product-registration.png (입력값과 사진 파일을 선택한 상품 등록 화면)
2. screenshots/result.png (같은 입력값을 POST로 전송한 결과 화면)

제출은 팀에서 한 번만 한다.

저장소 이름은 과제의 2026_osp_project_[TeamName] 형식에 맞춰 작성했다.

구현 확인
- /에서 index.html 출력
- 모든 페이지에 공통 내비게이션과 4개 링크
- 상품명, 판매자 ID, 가격, 주소, 상태, 이메일, 사진 입력
- multipart/form-data의 POST 요청으로 Flask에 전송
- result.html에서 입력값 6개와 상품 사진, 사진 파일명 출력
- 상품 목록, 리뷰 등록, 리뷰 목록에는 짧은 설명 출력
- python app.py 실행으로 로컬 서버 시작
- 가상환경과 캐시 파일은 제출 파일에서 제외

입력 예시는 시연용 정보이다. sample-product.jpg는 엽서 예시 이미지이다.
상품 정보는 결과 화면에 출력하며 데이터베이스에 저장하지 않는다.
